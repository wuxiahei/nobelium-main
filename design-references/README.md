# 水墨布局参考图

这是给视觉决策用的静态参考板，不是可直接上线的页面实现。

## 预览

打开 `ink-layout-options.html`，页面包含三种桌面布局：

- **A 墨间索引**：首页，内容密度优先。
- **B 沉浸阅读**：文章页，长文和公式优先。
- **C AI 学习室**：独立 `/ai`，会话与上下文分栏。

也可以直接查看导出的 PNG：

- `ink-layout-A.png`
- `ink-layout-B.png`
- `ink-layout-C.png`
- `ink-layout-options.png`：三套方案完整长图

## 决策方式

优先比较：

1. 水墨是否服务于阅读，而不是变成装饰背景。
2. 标题、文章入口、目录和公式是否一眼可找到。
3. AI 是否像一个独立工具，而不是覆盖博客内容的悬浮窗。
4. 移动端将三栏折叠后，主任务是否仍然清楚。

文件只用于讨论布局，本轮没有接入现有 Next.js 页面。
